# Introduction
Welcome to **libmmd** repository. This repository exists to give you tools for editing [Miku Miku Dance](https://learnmmd.com/how-to-mmd/download-mikumikudance-latest-version-mmd/) file formats.

# File formats
File formats with documentations

| File name | Documentation | Hexpat |
| :---: | :---: | :---: |
| VMD | [here](https://github.com/Antonio225t/libmmd/wiki/VMD) | [VMD.hexpat](https://github.com/Antonio225t/libmmd/blob/main/VMD/VMD.hexpat) |
| VPD | Not here[^1] | [VPD.hexpat](https://github.com/Antonio225t/libmmd/blob/main/VPD/VPD.hexpat) |
| PMX | Not here[^1] | [PMX.hexpat](https://github.com/Antonio225t/libmmd/blob/main/PMX/PMX.hexpat) |
| PMD | Not here | [PMD.hexpat](https://github.com/Antonio225t/libmmd/blob/main/PMD/PMD.hexpat) |

[^1]: Documentation for these formats can be found [here](https://gist.github.com/felixjones/f8a06bd48f9da9a4539f) (for PMX, by [Felix Jones](https://gist.github.com/felixjones)) and [here](https://mikumikudance.fandom.com/wiki/MMD:Polygon_Model_Data) (for PMD, by mikumikudance fandom).
